# Hospital_emergency_-room_analysis_project

---------------------------------------------------------------------------Hospital Emergency Room Analysis--------------------------------------------------------------------------------

This project analyzes emergency room (ER) data to identify trends, bottlenecks, and insights using *Power BI*. The goal is to support hospital administrators in improving efficiency and patient care.

 1. Dashboard Highlights

- *Patient Volume by Time & Day*
- *Wait Time Analysis*
- *Admission vs Discharge Trends*
- *Top ER Visit Reasons*
- *Demographics Breakdown*

 2. Tools Used

- *Power BI* – Dashboard creation and data visualization  
- *CSV File* – Hospital ER_Data.csv containing raw ER visit data  

 3. Files

| File | Description |
| Hospital ER_Data.csv | Raw dataset used for analysis |
| Hospital Emergency Room Analysis.pbix | Power BI dashboard file |

 4. How to Use

1. Open Hospital Emergency Room Analysis.pbix in Power BI Desktop.  
2. Load Hospital ER_Data.csv when prompted or from Power Query.  
3. Explore the visuals and adjust filters to discover key insights.
